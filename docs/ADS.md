# Advertising Reelio (simple)

1. Open `https://krvats.github.io/reelio/promote.html` (also works from your own address).
2. Choose where you will post (Instagram, WhatsApp...) and a campaign word. Tap **Copy link**. This link remembers where each visitor came from.
3. Copy the English or Hindi caption. Download a picture (Post = square, Story = tall).
4. Post it. Put the link in your Instagram bio or a Story link sticker. For posters use the QR code.
5. When someone taps **Message us** on the site, a small box gives them a message with a short code (like `instagram-launch`) to copy and send. When they message you, the code tells you which ad worked.

Optional counter (free, no cookies): make a name on goatcounter.com, then put `goatcounter: 'yourname'` in `web/app-config.js`.
Change the address shown on the pictures: `python tools/make_ads.py yourname.github.io/reelio`.
Rule: advertise only what is true (free demo, runs in the cloud, Hindi + English). Do not promise followers, views or earnings.
